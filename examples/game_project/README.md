# 小游戏期末项目：校园贪吃蛇（AI 评测示例）

> 这是一份用于演示 OJ Sentinel「作品评测 / AI 评测」的**虚构示例项目**，不来自任何真实学生。

## 任务

用 Python + tkinter 实现一个单机小游戏「校园贪吃蛇」：

- 20×20 网格，蛇初始长度 3，方向键控制；
- 随机生成食物，吃到食物蛇身 +1、分数 +10；
- 撞墙或撞到自己时游戏结束，显示最终分数；
- 按 R 重新开始，按 ESC 退出；
- 游戏速度随分数提高而加快（可选加分项）。

## 提交内容

`snake_game.py`、`README.md`（运行说明）、可选截图。

## 评分标准（100 分）

| 维度 | 分值 | 说明 |
| --- | --- | --- |
| 核心玩法 | 40 | 移动、吃食物、增长、计分、碰撞检测是否正确 |
| 交互与状态 | 20 | 方向控制、暂停/重开、游戏结束界面、速度变化 |
| 代码质量 | 20 | 结构清晰、命名合理、无重复逻辑、常量集中 |
| 健壮性与可运行性 | 20 | 启动不崩溃、非法输入/边界处理、依赖说明完整 |
